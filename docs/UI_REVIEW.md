# Mobile interface review

Direction: retain Together’s WholeMark-inspired forest green identity. A shared household checklist that feels calm, practical and personal. Meaningful color belongs to daily progress; three compact profile selectors identify the circle.

## Audit and changes

- Spacing: replaced irregular spacing with a 4px rhythm. Compact daily overview brings habits higher on the first phone screen. Habit rows share alignment and padding.
- Color: retained the existing green accent and pale neutral surfaces. Removed ornamental hero circles and colored icon tiles. Primary, secondary and muted text have defined roles.
- Icons: existing SVG icon language, 18px and 1.5 stroke. Removed decorative plant and text glyphs in favor of the existing logo asset.
- Copy: contextual page names replace greeting and motivational slogans. Progress reports actual daily goals and habits logged. Profile visibility is described accurately in Settings.
- Type: 400/500 with limited 600 emphasis. Tabular numbers. Phone labels are at least 11px, body copy 13–16px, inputs 16px.
- Layout: single-column habit rows on phones; responsive desktop grid. Four mobile tabs (Today, Our circle, History, More), retaining Templates, Trends and Settings in the More sheet. Existing section order preserved.
- Details: minimum 44px tap targets, bottom safe-area padding, accessible names for quick logging, visible focus, dismissible modal sheets, direct custom quantity action, optional password reveal, and an Undo action after a check-in.
- Visuals: real daily progress is the visual focus. No generated imagery or invented activity.
- Motion: short feedback and sheet entrance only. Progress uses transforms instead of animated width; reduced motion is honored.

History remains a readable list. Trend table rows adapt to labeled cards on phones. Habit forms stack their fields and keep their action row visible inside scrolling sheets. The data model and shared records are unchanged. Sign-in now uses a persistent 365-day cookie, renewed on authenticated reads, as requested in the follow-up.
